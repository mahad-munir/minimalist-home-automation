# Free Image Hosting via Your GitHub Repository

You can store your Pin graphics directly in this `images/` folder!

### How it works:
1. Save your pin images (e.g. `pin1.jpg`, `pin2.png`) inside this `images/` folder.
2. Commit and push your changes to GitHub.
3. Your public image URL on GitHub will be:
   `https://raw.githubusercontent.com/<YOUR-GITHUB-USERNAME>/<YOUR-REPO-NAME>/main/images/pin1.jpg`
4. Paste that URL directly into the `image_url` column of `pins.csv`!

### Recommended Pin Image Specs:
- **Aspect Ratio**: 2:3 Vertical
- **Resolution**: 1000 x 1500 px (or 1080 x 1920 px)
- **Format**: `.jpg` or `.png`
- **Design**: Large bold headline on top, high-contrast lifestyle image in background.
