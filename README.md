# Pinterest Automation: Autonomous Auto-Poster Bot

An automated, serverless Pinterest publishing bot powered by **GitHub Actions** and the **official Pinterest API v5**. 

It reads your queued pins from `pins.csv`, posts the next pending pin on a daily schedule, and automatically commits the updated status back to your GitHub repository — running 100% in the cloud with zero server costs and zero manual intervention required.

---

## What's Included

- `publish_pin.py`: Core publishing engine with input sanitization, character truncation (Title <= 100, Desc <= 500), API error diagnostics, and stuck-queue prevention.
- `get_initial_token.py`: One-time setup script that handles Pinterest's OAuth flow, generates your long-lived `refresh_token`, and automatically displays your **19-digit numeric Board IDs**.
- `list_boards.py`: Utility script to fetch and list all your Pinterest boards and their 19-digit IDs anytime.
- `validate_pins.py`: Pre-flight auditing tool that checks `pins.csv` for broken URLs, missing fields, or character limit issues before publishing.
- `.github/workflows/publish-pin.yml`: Daily automated cron workflow with pip caching, git rebase safety, and bot commit authorization.
- `images/`: Directory to store pin graphics for free, permanent image hosting via GitHub raw URLs.
- `BUSINESS_GUIDE.md`: Comprehensive business strategy guide covering niche selection, account setups, Canva templates, affiliate marketing, and Pinterest SEO.

## Step-by-Step Setup Guide

### Step 1: Install Python Dependencies
Open PowerShell or your terminal in this project directory:
```bash
pip install -r requirements.txt
```

### Step 2: Create a Pinterest Developer App
1. Go to [Pinterest Developer Portal](https://developers.pinterest.com/apps) and log in with your Pinterest Business account.
2. Click **Create App** and give it a name.
3. In App Settings, add Redirect URI: `https://localhost/callback`
4. Copy your **Client ID** and **Client Secret**.

### Step 3: Run the One-Time OAuth Setup
Run the setup script on your computer:
```bash
python get_initial_token.py
```
- It opens your browser to grant authorization to your app.
- Copy the resulting code (or full redirected callback URL) and paste it into the prompt.
- The script exchanges the code for your **refresh token** AND automatically displays your **19-digit numeric Board IDs**!

### Step 4: Add GitHub Repository Secrets
On GitHub, open your repository:
1. Go to **Settings → Secrets and variables → Actions**.
2. Click **New repository secret** and add the three secrets:
   - `PINTEREST_CLIENT_ID`: Your Pinterest App Client ID
   - `PINTEREST_CLIENT_SECRET`: Your Pinterest App Client Secret
   - `PINTEREST_REFRESH_TOKEN`: The refresh token generated by Step 3

### Step 5: Queue Your Pins in `pins.csv`
Open `pins.csv` and add your rows:
- `id`: Sequential number (1, 2, 3...)
- `status`: Set to `pending`
- `board_id`: Your 19-digit numeric Pinterest Board ID (run `python list_boards.py` to view yours)
- `image_url`: Publicly accessible image URL (e.g. GitHub raw URL, Unsplash, Imgur)
- `title`: Catchy headline (max 100 characters)
- `description`: Engaging description with SEO keywords and `#ad`/`#affiliate` tag (max 500 characters)
- `link`: Your destination URL (affiliate link, blog post, or product page)
- `alt_text`: Image description for accessibility and search ranking (optional)

### Step 6: Validate Your Pins Locally
Before pushing, run the pre-flight validator to ensure your CSV is clean:
```bash
python validate_pins.py
```
You can also run a dry-run test of the publishing engine:
```bash
python publish_pin.py --dry-run
```

### Step 7: Push to GitHub & Relax!
Commit and push your files to your GitHub repository:
```bash
git add .
git commit -m "Add pins queue"
git push origin main
```
The bot will now trigger automatically every day at 14:00 UTC (or click **Run workflow** manually anytime inside GitHub's **Actions** tab).
