# Privacy Policy for Minimalist Home Automation

*Last updated: September 10, 2026*

This application ("Minimalist Home Automation") is a private, personal automation tool used solely by the account owner to schedule and publish original home decor and organization content to their own Pinterest Business account via the official Pinterest API v5.

## 1. Information We Collect
This application does not collect, sell, or share any personal information from external users. It only uses authentication credentials (OAuth refresh token and API keys) securely stored in GitHub Actions encrypted repository secrets to communicate with the Pinterest API on behalf of the account owner.

## 2. Use of Pinterest Data
The application interacts strictly with the Pinterest API for:
- Reading board metadata (names and IDs) belonging to the authenticated account.
- Creating and scheduling Pins (titles, descriptions, images, and links) authored by the account owner.
No third-party user data is accessed, processed, or stored.

## 3. Data Storage & Security
- All API credentials are encrypted via GitHub Secrets.
- No personal user data is ever transferred to third parties or advertising networks.

## 4. Contact
For any questions regarding this privacy policy, please contact via the GitHub repository: https://github.com/mahad-munir/minimalist-home-automation
